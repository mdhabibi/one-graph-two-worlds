# When do two recommendation queries mean the same thing?

Dr. Mahdi Habibi · Working module · 16 November 2026

Start with [the equivalence study](equivalence/README.md). It compares the book’s
recommendation query pair under a declared contract and investigates deliberate
counterexamples. The executable evidence is separate from the protocol and its
conditional proof argument.

Read `Research-Companion-Equivalence.pdf` for the illustrated report, or use
`equivalence/PROTOCOL.md` and `equivalence/derived/RESULTS.md` directly. The Python runner,
source fixtures, raw query output, exact runtime identity, and input hashes are
included so results can be inspected and reproduced.

This is a locally prepared research module for review, not a replacement for the
published book, a new DOI deposit, a performance benchmark, or a peer-reviewed
paper. Integration into a future edition will follow review and the existing
publication process. The current book remains at
https://doi.org/10.5281/zenodo.24209667.
