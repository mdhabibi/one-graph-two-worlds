# Version 0.2.0 release notes

Version 0.2.0 of **Knowledge Graphs: Semantic Graphs and Property Graphs**, by Dr. Mahdi Habibi, published on 17 November 2026.

- [Read the archived book and companion materials](https://zenodo.org/records/24316420)
- [Edition DOI](https://doi.org/10.5281/zenodo.24316420)
- [All versions](https://doi.org/10.5281/zenodo.24209667)

This 173-page public review edition adds a conditional recommendation-query equivalence argument and an inspectable bounded experiment. Five integrated additions cover semantic evolution and dated policy replay, eligibility versus suitability, reasoning value versus cost, identity and evidence, and missing-data validation. It includes 183 explained review questions, updated glossary/navigation, three executable extensions and two discussion worksheets.

Local checks passed for the document/package, RDF lab, Neo4j Community 5.26.30 and targeted HermiT examples, 23 deliberate defects and five rebuild controls. A repeat local build produced identical PDF bytes. [Both GitHub Actions jobs passed on the archived source commit](https://github.com/mdhabibi/one-graph-two-worlds/actions/runs/44120988200).

The retained experiment has 145 controlled cases: 143 aligned cases agree and two boundary counterexamples intentionally differ. Independent paired reproduction remains open. These results do not establish general RDF/LPG equivalence, production performance, personal suitability or formal accessibility conformance.
